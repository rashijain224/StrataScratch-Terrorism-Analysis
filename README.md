\# StrataScratch Terrorism Data Analysis



\## About

Exploratory data analysis of terrorist incidents using Python and Pandas.



\## Tools Used

\- Python

\- Pandas

\- Matplotlib

\- GeoPandas



\## Analysis

1\. Terrorist incidents over the years

2\. Incidents vs casualties

3\. Most common attack methods

4\. Regional and time-based attack analysis

5\. Geographic spread of attacks



\## Visualizations

\- Yearly incident trends

\- Incidents vs casualties scatter plot

\- Attack method analysis

\- Geographic attack distribution map
