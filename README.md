# StrataScratch Terrorism Data Analysis

## 📌 Project Overview

This project explores global terrorism incidents using Python and data analysis techniques.

The analysis focuses on identifying trends over time, relationships between incidents and casualties, common attack methods, regional differences, and the geographical spread of attacks.

This project was completed as part of a StrataScratch data analysis practice project.

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- GeoPandas
- Jupyter Notebook
- Power BI

---

## 🔍 Analysis Performed

### 1. Terrorist Activities Over the Years

Analyzed how the number of terrorist incidents changed over time and compared trends across different regions.

**Visualization:**
- Yearly global incident trend
- Regional incident trends

---

### 2. Incidents vs Casualties

Analyzed the relationship between the number of terrorist incidents and total casualties.

Total casualties were calculated as:

**Killed + Wounded**

A correlation analysis and scatter plot were used to identify the relationship and possible irregularities.

---

### 3. Most Common Attack Methods

Identified the most frequently used attack methods.

The analysis was further compared across:

- Different regions
- Different years

This helps identify how attack patterns vary geographically and over time.

---

### 4. Geographical Spread of Attacks

Used geographical coordinates to visualize the locations of recorded terrorist incidents around the world.

**Tools used:**
- GeoPandas
- Matplotlib

The resulting map provides a visual representation of the regional distribution of recorded attacks.
